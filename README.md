# A-Grounded-Human-in-the-Loop-Architecture-for-Dynamic-Partially-Observable-Systems
The Universal Adaptive Core (UAC) is a proposed architectural framework for decision-support systems operating on dynamic systems where the underlying state cannot always be observed directly, evidence arrives over time, uncertainty remains, and actions change the system being observed.
